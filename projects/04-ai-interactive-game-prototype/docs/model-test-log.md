## 评估维度

- **一致性**：角色身份、口吻、设定在多轮对话中是否稳定。
- **连贯性**：剧情承接、因果关系、分支选择是否前后自洽。
- **可控性**：输出格式、长度、边界是否符合预期。

## 可复用的 Prompt 优化思路

1. **显式列出不可违背的设定**：身份、性格、说话习惯写成条款，而不是一句笼统描述。
2. **每轮携带上下文摘要**：把已发生剧情和玩家目标回填进 prompt，缓解长对话遗忘。
3. **固定输出格式**：先回应、后选项，顺序与长度固定，便于程序解析和后续接入分支逻辑。
4. **边界前置**：明确禁止出戏、剧透、超出设定作答，并给出遇到越界问题时的处理方式。
5. **按维度做对照测试**：同一输入跨版本跑，按一致性 / 连贯性 / 可控性分别记录，再决定下一轮改哪里。
