# AI 互动玩法方案 · 《雨夜电台》

> 基于同类产品调研与原型测试，输出可落地的文字向 AI 互动玩法。

## 一、调研摘要

- 参考方向：AI 文字对话游戏、角色陪伴类产品、互动叙事小说。
- 常见交互形式：自由对话、选项分支、固定角色陪伴、多线剧情推进。
- 可借鉴的点：
  - 用强人设角色承载对话，降低玩家理解成本；
  - 选项分支 + 自由输入混合，既保证剧情可控，又留出表达空间。
- 现存不足 / 机会点：
  - 多数产品角色设定容易在长对话后漂移；
  - 线索与分支关系松散，玩家选择难以影响结局；
  - 缺少统一的氛围包装，对话沉浸感偏弱。

## 二、核心玩法创意：热线来电式分支对话

### 创意概述
玩家以"深夜电台听众"身份接入节目，AI 主播林晚通过热线对话引导玩家倾诉与选择；对话中积累的**线索值**、**情感值**、**悬念值**三类倾向，决定后续出场角色与最终结局走向。

### 交互流程
1. **进入节目**：玩家收听开场，选择以哪种心情打进热线。
2. **热线对话**：林晚回应玩家，每轮给出 2~3 个分支选项，也支持自由输入。
3. **倾向积累**：玩家选择被归类到线索 / 情感 / 悬疑三条路线，实时更新倾向值。
4. **角色与剧情解锁**：倾向值达到阈值后，解锁对应嘉宾来电或隐藏剧情片段。
5. **结局收敛**：多轮对话后按主导倾向进入不同结局，保留一段可回看的对话记录。

### 依赖的模型能力
- 角色一致性对话（靠角色设定模板约束）；
- 分支推理与剧情承接（靠剧情分支模板与已确定事实清单）；
- 自由输入的意图归类，映射到三条倾向路线。

### 落地难度：中
- 难点：长对话设定保持、自由输入到倾向值的归类、分支与结局的对应关系。
- 可控做法：先用固定选项分支跑通主线，自由输入作为补充；倾向归类用规则 + 关键词起步，再迭代模型判断。

## 三、备选创意

### 创意 2：多嘉宾连麦
- 核心体验：不同性格的嘉宾轮番来电，玩家在多方对话中拼凑事件真相。
- 交互流程：主播串联 → 嘉宾发言 → 玩家追问 → 线索合并。
- 落地难度：高（多角色关系切换与设定约束更复杂）。

## 四、优先级建议

| 创意 | 预期价值 | 实现成本 | 建议优先级 |
|---|---|---|---|
| 热线来电式分支对话 | 沉浸感强、闭环清晰 | 中 | P0，先做最小原型 |
| 多嘉宾连麦 | 剧情层次更丰富 | 高 | P1，主线跑通后扩展 |
