# 04 · AI 互动游戏原型探索：《雨夜电台》

> 方向：AIGC 应用验证 · Prompt 工程 · 玩法调研与原型设计　|　角色：独立发起人　|　周期：2024.10 – 至今

## 背景与目标

自主发起文字向 AI 互动游戏原型，验证大模型在**角色对话 + 剧情分支**场景下的交互效果与可行性。原型定名《雨夜电台》：玩家以深夜电台听众身份接入热线，AI 主播林晚通过对话引导玩家倾诉与选择，不同选择累积为不同剧情倾向。

目标：
- 跑通"角色对话 → 分支选择 → 倾向积累"的基本玩法闭环；
- 评估模型输出的一致性、连贯性与可控性；
- 沉淀可复用的 Prompt 优化思路与一套可落地玩法方案。

## 需求拆解

1. 明确验证范围：聚焦文字向游戏中的 AI 角色对话与分支剧情交互。
2. 设计并迭代游戏化提示词，覆盖角色设定与剧情分支两类场景。
3. 对模型输出做对照测试，记录稳定性与逻辑连贯性问题，形成测试记录。
4. 调研同类 AI 互动玩法，提炼新交互创意，输出可落地的玩法方案。

## 技术栈 / 工具

- 大模型对话与 Prompt 工程：角色设定、剧情分支类提示词设计与三轮迭代
- 测试与记录：跨版本对照测试、问题归类、文档化沉淀
- 玩法设计：分支路线划分、倾向值积累、结局收敛

## 实现要点

### Prompt 设计与迭代
- 独立设计并迭代多套游戏化提示词，撰写角色设定、剧情分支类 prompt，累计优化 **3 版模板**。
- V1 建立基础人设；V2 补入行为边界、说话习惯与称呼约束；V3 加入上下文摘要、固定输出格式与长度限制。
- 模板文件：[prompts/character-setting.md](prompts/character-setting.md)、[prompts/story-branch.md](prompts/story-branch.md)。

### 模型测试与评估
- 对大模型输出做跨版本对照测试，按**一致性、连贯性、可控性**三个维度记录问题。
- 典型问题：口吻漂移、出戏剧透、分支与前文矛盾、回答过长、选项与选择脱节。
- 整理形成测试记录文档，总结可复用的 Prompt 优化思路，见 [docs/model-test-log.md](docs/model-test-log.md)。

### 玩法调研与创意输出
- 调研 AI 文字对话、角色陪伴、互动叙事类产品，梳理可借鉴点与机会点。
- 输出核心创意"热线来电式分支对话"：线索 / 情感 / 悬疑三条路线积累倾向值，解锁角色与结局；另列多嘉宾连麦备选方案，见 [docs/gameplay-proposal.md](docs/gameplay-proposal.md)。

## 遇到的问题与解决

- **角色口吻漂移、长对话后设定遗忘**：在模板中显式列出身份、性格、说话习惯等不可违背条款；每轮回填上下文摘要；按 V1→V3 逐步收敛。
- **模型出戏、提前剧透**：在行为边界中明确禁止跳出角色、禁止解释为 AI、禁止剧透，并规定越界问题的回避方式。
- **分支回答与前文矛盾、选项脱节**：模板前置"已确定剧情事实（不可推翻）"清单；要求先承接玩家选择，再给出标注路线类型的分支选项。
- **回答过长打断节奏**：限定回应长度（默认 2~4 句、关键信息不超过一段），固定"先回应后选项"的输出顺序。

## 收获与可改进

- 收获：摸清大模型在游戏对话场景的能力边界；掌握 Prompt 设计、跨版本对照测试与问题沉淀的方法；形成从玩法调研到方案输出的完整思路。
- 可改进：接入模型 API 做成可交互原型；为倾向归类补充量化评测指标；把角色设定、分支事实整理成结构化可复用配置；扩展多角色同场对话的关系约束。
