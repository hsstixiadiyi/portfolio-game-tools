# 剧情分支 Prompt 模板 · 已填示例（场景：第一通热线）

> 用途：根据玩家选择推进剧情，维持分支逻辑连贯，避免前后设定矛盾。
> 下方【】内为示例内容，可替换为其他剧情节点。

## 模板正文（V3）

```
当前剧情节点：【第一通热线 · 雨夜来电】
已确定的剧情事实（不可推翻）：
1. 外面连续下了一周雨，今晚电台热线异常拥挤。
2. 林晚正在播放听众点播的老歌，这首歌在台里没有点播记录。
3. 玩家刚打进电话，说自己也听到了这首老歌。

玩家刚才的选择：【玩家输入：我想知道这首歌是谁点的】

请基于以上信息推进剧情：
1. 延续既有设定与因果，不新增与已确定事实冲突的内容。
2. 先输出林晚的角色回应，再描述当前情境。
3. 给出 2~3 个玩家可选择的行动分支，每个分支用一句话概括。
4. 若玩家选择导致路线分叉，标记该分支对应的后续走向。
```

## 示例输出（供对照）

> **林晚**：这位听众，你说的那首歌，导播那边查不到点播记录……今晚打来问同一件事的，你不是第一个。
>
> 雨声从直播间隙里漏进来。她停顿了一下，麦克风轻轻响了一声。
>
> **你可以选择：**
> - **A. 追问歌名和歌词细节** —— 走线索收集路线，拼凑歌曲来历。
> - **B. 说出自己最近反复梦到的场景** —— 走情感共鸣路线，拉近与林晚的距离。
> - **C. 询问电台以前是否发生过类似的事** —— 走电台历史/悬疑路线。

## 分支状态约束

- 已发生事件记录在"已确定剧情事实"中，后续分支必须承接，不可推翻。
- 角色立场与关系变化要在分支中体现，不可随意回退。
- 输出顺序固定：先角色回应与情境，后选项，便于后续接入程序解析。
- 每条分支标注后续走向类型（线索 / 情感 / 悬疑），方便控制节奏与结局权重。
