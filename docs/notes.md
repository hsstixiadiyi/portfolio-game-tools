# 项目笔记

## 通用记录模板

### 项目：[雨夜电台]

- **原始需求**：[打造沉浸式AI陪伴电台，搭配雨声背景，提供情绪倾听、松弛聊天的电台体验]
- **需求拆解**：
  1. [设计雨夜氛围感界面，接入雨声背景音频]
  2. [设定电台主播人设，编写约束prompt，控制温柔松弛的说话风格]
- **关键决策**：[选用提示词驱动对话，不做模型微调；优先保证氛围感，采用轻量化网页原型开发]
- **踩坑记录**：
  - 现象：[AI回复容易说教、语气生硬，脱离电台轻声陪伴的感觉 ]
  - 排查过程：[ prompt缺少人设和篇幅限制，容易输出长篇大道理]
  - 解决方式：[补充人设边界，限制回复长度，增加松弛口语风格约束 ]
- **可量化结果**：[完成3版prompt迭代，多轮对话稳定可用，基础原型功能完成]
